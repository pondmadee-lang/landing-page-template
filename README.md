# Landing Page Template

A clean, modern, fully static landing page template — a reusable starting point
for any product or service landing page. No build step, no JavaScript required.

## Files

| File | Description |
| ---- | ----------- |
| `index.html` | The landing page markup |
| `styles.css` | Styles: colors, typography, layout, responsive breakpoints |

## Quick start

1. Copy `index.html` and `styles.css` into your site folder (or serve this repo as-is).
2. Open `index.html` in a browser to check that it looks right.
3. Replace every `{{…}}` placeholder with your real content.

## Customizing

- **Colors:** change the `--color-*` variables in `styles.css`.
- **Fonts:** update `--font-main`.
- **Sections:** add or remove `<section>` blocks in `index.html` and the matching CSS rules in `styles.css`.
- **Mobile:** tweak the `@media (max-width: 768px)` block for a different breakpoint.
